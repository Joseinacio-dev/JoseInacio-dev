## 🚀 Projeto em destaque

### DiagPro

O **DiagPro** é meu principal projeto pessoal.

É uma aplicação desenvolvida com foco em auxiliar assistências técnicas no diagnóstico e gerenciamento de dispositivos.

O projeto surgiu com o objetivo de aplicar conhecimentos de programação na criação de uma solução para um problema real, passando por diferentes etapas de desenvolvimento, organização, testes e aprimoramento.
